# MesTTo (github.com/MesTTo): what we can use

Research notes from 2026-10-03.

MesTTo is the personal GitHub account of Ahmad Mesto, an AGI engineer at
SingularityNET. It has about 23 repositories, all pushed between June and
September 2026. Nearly all are Apache-2.0 or MIT.

How each claim was checked:
- **Ran here:** `tsmetta` and `@mettascript/*` were installed and run under
  Node 22.
- **Read in code:** the source was read but not run.
- **README only:** taken from the project's README.

## Verified by running

- **TSMeTTa** (npm `tsmetta`, alpha) is a patched SWI-Prolog compiled to WASM.
  It runs in Node and in the browser.
  - It boots in about 1.5 s.
  - It loaded **our `lib_nal.metta` and `lib_pln.metta` unchanged** and
    evaluated them correctly.
  - `m.trace(src)` returns events shaped like
    `{seq, depth, kind: call|exit|fail, term, answer}` plus a stop reason.
  - `m.derivation(term)` returns proof trees whose leaves are facts tagged with
    their source space. That is a provenance primitive we can use directly.
  - `subscribe(space, pattern)` streams add/remove events.

## Read in code

- **MeTTa engine** (a PeTTa fork with large extensions)
  - `engine/tracer.pl` provides `observe` and a breakpoint/resume debug mode.
  - It does **not stream**: events are read at the end of a session.
- **PERFORMANCE.md and the `metta-benchmarking` extension** describe the
  measurement discipline we copy for Crucible:
  - instruction or inference counts, not wall time;
  - subtract an empty-program control run;
  - take the minimum of 3 runs after a warm-up;
  - two-sided bands against a baseline, so an improvement past the band
    re-pins the baseline;
  - stamp each result with the measurement configuration;
  - "refused measurement" is a separate outcome from "regression".
- **`@mettascript/debug` `compareRuns`** diffs two traces: it aligns them by
  hash, ignores renumbered fresh variables and separates substantive hunks. We
  use it as the champion-versus-candidate trace diff.
- **`metta-otel`** maps reduction traces to OpenTelemetry spans nested by depth.
- **MeTTa-LSP** is an LSP, CLI, MCP server and browser IDE, and it **already
  ships an OmegaClaw plugin** with check, test, run, explain and other skills.
- **`omegaclaw-deontic`** (MIT) installs onto OmegaClaw as an overlay. It adds
  defeasible, deontic and temporal norms. We use it as a flourishing and policy
  gate.
- **PeTTaChainer πPLN** keeps per-context positive and negative evidence counts.
  That fits a commons where agents disagree.
- **`oh-my-goals`** (MIT) does retraction-aware invalidation with proofs.

## README only

- **MeTTaScript `<metta-grapher>`** (MIT): an animated reduction graph as a web
  component.
- **`metta-tui-debugger`**: step-back, mutation breakpoints and atomspace diffs.
  Use it as a UX reference; it runs on Hyperon, not PeTTa.
- `tsmetta` live views, remote access and transactions.
- MeTTa-MORK.

## Licenses and risks

- **Avoid:** `metta-on-mork` (GPL-2.0) and MeTTaScript's `obc-fixture.ts`
  (GPL-3.0).
- **No license, so ask before reusing:** `OmegaClaw-GoalChainer`.
- Every repository has a single author. TSMeTTa is alpha. The engine's
  semantics diverge from upstream PeTTa, and a Rust rewrite has been announced.

## What we take from it (in PLAN.md)
